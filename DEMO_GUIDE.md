# RockfallAI Demo Guide & Presentation Script

This guide outlines a step-by-step presentation walkthrough for evaluating the **RockfallAI** prototype during project defense, faculty evaluation, or technical review.

---

## 1. Quickstart & Service Launch

### Step 1: Start Backend (Terminal 1)
```powershell
cd "e:\Individual Project\backend"
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
- Verify: Open `http://localhost:8000/docs` in your browser.
- Check: `GET /health` confirms `status: "healthy"` and `demo_mode: true`.

### Step 2: Start Frontend (Terminal 2)
```powershell
cd "e:\Individual Project\frontend"
npm run dev
```
- Access the application at `http://localhost:5173`.

## 2. 5-Minute Evaluation Walkthrough

### Part 1: Executive Dashboard & Subsystem Health (2 mins)
1. **Notice the Header:**
   - Note the **DEMO MODE: Synthetic Data** badge and academic prototype disclosure.
   - Point out the **subsystem status pills**:
     - `CNN-LSTM`: Trained
     - `GenAI`: Anthropic Claude (or Demo Fallback)
     - `Weather`: Synthetic Demo (or OpenWeather)
2. **AI Situation Summary:**
   - Click **"Generate Site Summary"**.
   - Explain how this provides an autonomous cross-sector briefing aggregating highest-risk pit highwalls and immediate tactical directives.
3. **Sector Overview & Risk Matrix:**
   - Highlight the 4 monitored pit zones: `ZONE-A` (South Highwall), `ZONE-B` (East Quarry), `ZONE-C` (Active Fault), `ZONE-D` (West Portal).
   - Click on different zones to observe real-time telemetry inspection in the detail panels.

---

### Part 2: Interactive Operational Scenarios (2 mins)
Demonstrate how the system handles different mining conditions using the **"Scenario Preset"** dropdown in the header:

1. **Preset: "Scenario: Normal Baseline"**
   - Telemetry settles to baseline: PPV < 3.0 mm/s, displacement < 1.0 mm, rainfall nominal.
   - Risk levels transition to **LOW** (green `#10b981`).
   - No unnecessary alerts are generated.
2. **Preset: "Scenario: High Rainfall"**
   - Rainfall increases to 26 mm/h; joint pore pressure rises.
   - Risk transitions to **HIGH** (orange `#f97316`).
   - Notice automatic generation of safety inspection advisory.
3. **Preset: "Scenario: Critical Instability"**
   - Heavy storm + blasting vibration causes displacement rate to accelerate (> 14 mm).
   - Risk transitions to **CRITICAL** (red `#ef4444`).
   - Notice the high-visibility banner and restriction advisory.

---

### Part 3: Alert Lifecycle & Deduplication (1 min)
Navigate to the **Alerts** page:
1. **Deduplication Demonstration:**
   - Return to Dashboard and click **"Simulate Telemetry Tick"** multiple times while in the same risk tier.
   - Check Alerts page: Point out that **duplicate identical alerts were suppressed** by the deduplication engine.
2. **Alert Escalation:**
   - Show how transitioning from MODERATE to CRITICAL creates an escalated incident notice.
3. **Operator Acknowledgment:**
   - Click the green **"ACKNOWLEDGE"** button on an active critical alert.
   - Observe the unacknowledged counter decrements in the header while the audit record remains preserved in the database.

---

### Part 4: Prediction Studio & ML Benchmarks (1 min)
Navigate to the **Predictions** page:
1. **Spatial-Temporal Input Form:**
   - Click preset buttons (`ZONE-A`, `ZONE-C`) to auto-populate terrain morphology and sensor channels.
   - Click **"Execute Model Inference"**.
   - Show the real-time continuous **0–100 risk score** and identified contributing factors.
2. **Explainable AI Integration:**
   - Click **"Generate AI Explanation"**.
   - Review the causal analysis generated by Claude (or the zero-key fallback engine).
3. **Benchmark Comparison Table:**
   - Point out the empirical comparison table:
     - **CNN-LSTM:** MAE 1.14, RMSE 1.41, Accuracy 97.67%, F1 97.68%
     - **Random Forest:** MAE 1.11, RMSE 1.37, Accuracy 97.33%, F1 97.33%
     - **XGBoost:** Displays status badge without breaking if not installed.

## 3. Reviewer FAQ

- **Q: Are real mine lives dependent on this system today?**
  - **A:** No. This is an academic/hackathon prototype utilizing synthetic and simulated telemetry streams. It is architected with production-ready interfaces for future IoT integration.
- **Q: What if the internet cuts out during the demo?**
  - **A:** The system has 100% offline resilience. The deterministic zero-key fallback engine will generate accurate, physics-consistent explanations with no external API dependency.
- **Q: Does GenAI compute the risk score?**
  - **A:** No. The PyTorch CNN-LSTM neural network deterministically computes the numerical risk score. GenAI is strictly limited to explaining the model's findings.
